# legacy/ — the v2 system, frozen

This is the karaoke generator as it stood before the v3 rebuild (Flask + Celery + Demucs +
WhisperX 3.1.3 + MoviePy). It is kept only as a reference while the v3 pieces replace it, it is
excluded from lint and CI, and it gets deleted in conversation C9 of the v3 plan.

To run the old system, check out the `v2-final` tag, where these files still live at the repo
root, and follow the README and `docs/05-runbook.md` from that commit.
